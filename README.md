# 🧮 Smart Calculator – Java Swing

A desktop-based Smart Calculator built using **Java Swing**. This project is designed to practice Java GUI development, object-oriented programming, event handling, and basic mathematical operations.

## ✨ Features

- Clean and user-friendly graphical interface
- Three-panel layout for organized UI
- Number and operator buttons
- Basic arithmetic operations
- Interactive button functionality
- Custom panel colours and styling

## 🛠️ Technologies Used

- Java
- Java Swing
- AWT
- Object-Oriented Programming (OOP)

## 📂 Project Structure

```text
SmartCalculator/
│
├── Main.java
├── UI.java
└── README.md
```

### File Description

- **Main.java** – Application entry point.
- **UI.java** – Handles the calculator interface, panels, buttons and display.
- **Logic.java** – Handles calculator operations and calculations.

## 🚀 How to Run

1. Clone this repository.
2. Open the project in VS Code or your preferred Java IDE.
3. Compile the Java files.
4. Run `Main.java`.

## 🎯 Learning Outcomes

Through this project, I practised:

- Java Swing GUI development
- JFrame and JPanel
- JButton and JTextField
- Layout Managers
- ActionListener and ActionEvent
- OOP concepts
- Separating UI and calculation logic
